# Password Generator 🔐

A secure, random password generator built with Python's `secrets` module.

## ✨ Features
- Generate passwords 8-32 characters long
- Option to include/exclude symbols
- Cryptographically secure random generation
- User-friendly CLI menu
- Daily usage limit (5 passwords per session)

## 🚀 Quick Start

bash
# Clone the repo
git clone https://github.com/0xdarrt/python-monitor.git

## 🛠️ Technologies Used
- Python 3.x
- `secrets` module (cryptographically secure)
- `string` module
